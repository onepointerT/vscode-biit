# VSCode BIIT

### Bookmarking Issues and Issue Tracking for Visual Studio Code

##### v0.0.1

This extension enables Visual Studio Code to track issues with bookmarks at your code lines
ordered by project milestones. You could create a bookmark and write and issue for it or collide and enumerate code lines that are affected by your issue as bookmark of the issue and reference your issues by milestones that thus can be seen at your code and files.
